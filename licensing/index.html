    📋 Frequently Asked Questions¶

    Can I use CORE license for commercial projects?¶

    No, the CORE license is limited to research and educational use only. For commercial use, you need a PRO or ENTERPRISE license.

    What happens if my license expires?¶

    Classes will fail to instantiate with clear error messages. Renew your license to restore functionality.

    Can I upgrade from CORE to PRO?¶

    Yes, license upgrades are available. Contact bajpaikrishna715@gmail.com for upgrade pricing.

    Is there a trial version available?¶

    The CORE license serves as our trial version, providing access to fundamental features for evaluation.

    Can I use the framework offline?¶

    Yes, once licensed, the framework works offline. However, initial license validation requires internet connectivity.
